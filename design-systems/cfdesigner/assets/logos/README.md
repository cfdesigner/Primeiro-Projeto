# Logos

Arquivos originais do logo cfdesigner, PNG com fundo transparente.

- `cfdesigner-horizontal-white.png`: símbolo + nome lado a lado, tinta única **branca**. Banners, assinatura de vídeo, cabeçalho de portfólio. Só sobre `void`, `petrol` ou foto escurecida.
- `cfdesigner-stacked-white.png`: símbolo sobre o nome, **branco**. Capas e finais de vídeo.
- `cfdesigner-symbol-white.png`: só o símbolo, **branco**. Marca d'água, barras do Reel, favicon em fundo escuro.
- `cfdesigner-stacked-metal.png`: versão metálica (prata, grafite, bronze) com o nome em grafite. Foto de perfil, capa de portfólio, fundos claros.
- `cfdesigner-symbol-metal.png`: só o símbolo metálico. Avatar do Instagram/Fiverr/Upwork e abertura de vídeo.

Use pelo componente `Logo`. Nunca recolorir, distorcer ou recriar.
