# ServiceCard

Pacote de serviço (Fiverr gigs, propostas Upwork, página de preços). Título, preço em Bebas, lista de entregáveis com marcador âmbar e um botão.

- Fornecido pelo consumidor: `title`, `price`, `unit`, `items` (entregáveis concretos: duração, revisões, prazo), `badge`, `featured`, `cta`.
- `featured` em um só card por linha: borda âmbar e botão primary. Os outros usam ghost.
- Os preços do preview são exemplos.
