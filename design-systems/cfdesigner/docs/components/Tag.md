# Tag

Rótulo curto em caixa alta para formato, ferramenta ou estado. `amber` para o diferencial (AI + Adobe), `petrol` para categoria (Short-form, Storytelling), `rec` só para "ao vivo"/gravando, `time` para timecode e duração, `neutral` para especificações (4K, 24 fps).

- Fornecido pelo consumidor: `children` (uma a três palavras) e `tone`.
- No máximo três tags por card.
