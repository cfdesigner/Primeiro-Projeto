# Testimonial

Depoimento de cliente, para o destaque "Clients", propostas e portfólio. Frase em Montserrat 600, autor e contexto embaixo, estrelas em `amber-text`. A linha superior em `petrol` separa do fundo.

- Fornecido pelo consumidor: `quote` (citação real, sem editar o sentido), `author`, `context` (projeto, cidade), `rating`.
- Use só depoimentos reais. O do preview é exemplo.
